# kurdish-portfolio

پۆرتفۆلیۆیەکی کوردی بۆ پیشاندانی کار و پڕۆژەکان

Requires Node.js 20+. Run `npm install --ignore-scripts`, then `npm run dev`. Build: `npm run build`. Deploy `dist/` to a static host after building. Contact details are placeholders. This starter has no backend, checkout, authentication or database.
